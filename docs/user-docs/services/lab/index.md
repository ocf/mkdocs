---
title: Computer Lab
---

The OCF computer lab is located in 171 MLK Student Union and hosts 29 workstations running [NixOS](https://nixos.org/), as well as scanners, standing desks, and a Blu-ray/DVD/CD reader/writer. For more information and up-to-date hours, check the <a href="https://ocf.io/lab">main lab page</a>.

For details about printing in the lab specifically, see [Printing](printing.md).

If reserving the lab space for an event, please refer to the [reservation policy](lab-reservation-policy.md) and submit a request in the linked form.
